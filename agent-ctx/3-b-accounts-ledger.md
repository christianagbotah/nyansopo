## What shipped

### 1. API — `src/app/api/school/[id]/ops/accounts/route.ts` (702 lines)
Ops-route style: `opsAuth` + action-dispatch POST. Permissions: GET `["accounts.view"]` (non-strict — association officers keep read oversight), POST `["accounts.manage"]` (ACCOUNTANT/SUPER_ADMIN yes; TEACHER/CASHIER → 403, verified by smoke).

- **GET** (default) → full module payload: `accounts` (with live `balanceCents`), `journals` (last 50, lines included, per-entry `totalDebitCents/totalCreditCents/balanced`), `bankAccounts` (with `currentBalanceCents = opening + Σsigned txns`, `txnCount`, `reconCount`, `openReconId`), `reconciliations` (last 20, `itemCount/matchedCount`), `dashboard` (assets/liabilities/equity totals, revenue/expenses/surplus MTD, `journalCounts` by status, `unmatchedTxnCount`, `bankTotalCents`, `openReconCount`, `activeAccountCount`). `?bankAccountId=` adds that account's txn feed (`bankTxns`, last 100).
- **GET `?action=recon&id=`** → reconciliation workspace: recon + items (with linked `bankTxn`), `systemTxns` (unreconciled feed, `inUse` badge for txns already linked to a line of THIS recon), `expectedCents` (opening + Σsigned txns ≤ statement date), `differenceCents` = statementEnd − expected.
- **GET `?report=`** → `trial-balance` (net balance in the natural column, `totalDebitCents/totalCreditCents/balanced`), `balance-sheet` (`assets/liabilities/equity`, `netIncomeCents` = revenue − expenses to date, `checkCents` = A − L − E − NI, `balanced`), `income-statement` (date-ranged `revenue/expenses`, `totalRevenueCents/totalExpenseCents/surplusCents`), `general-ledger` (`&accountId=` required; `openingCents`, lines with `runningCents`, `closingCents`, `debitNormal`). All four take `&format=csv` → `text/csv` + `content-disposition` attachment.
- **POST actions**: `save-account` (type enum, per-school code uniqueness → 409, self-parent + walk-up cycle guard), `delete-account` (409 when journal lines / bank links / children exist), `save-journal` (≥2 lines, each exactly one side, ΣDr === ΣCr; DRAFT only editable — posting replaces lines in a transaction; `JE-YYYY-####` allocated transactionally from max existing), `post-journal` (re-validates balance, sets `postedAt/postedByName`; POSTED/VOIDED → 400), `void-journal` (POSTED → VOIDED; drafts → 400 "deleted, not voided"), `delete-journal` (drafts only), `save-bank-account` (links to a chart account; warns when it isn't flagged `isBank`), `delete-bank-account` (409 with txns/recons), `add-bank-txn` (DEPOSIT/WITHDRAWAL, integer cents > 0, source enum), `delete-bank-txn` (409 when referenced by a recon line), `create-reconciliation` (409 duplicate open recon per bank account), `add-statement-item` (signed cents, non-zero; auto-`matched` when a linked txn's amount agrees), `match-item`/`unmatch-item`/`remove-item` (read-only once COMPLETED), `auto-match` (CI3 heuristic: |amount|+direction+date ±3 days, then amount+direction; skips already-used/reconciled txns), `complete-reconciliation` (transaction: 400 if any line unmatched; stamps status COMPLETED + `completedAt` + `reconciledAt` on every linked BankTxn), `delete-reconciliation` (IN_PROGRESS only — completed is history).

## Semantics decisions (documented once in the route header, used everywhere)
- **Live-computed balances**: no cached balance column anywhere — `balanceCents = Σdebits − Σcredits` (debit-normal ASSET/EXPENSE) or the reverse (credit-normal), always recomputed from POSTED lines, so post/void can never drift.
- **VOIDED entries stay visible but are inert** — excluded from every balance and report (CI3 parity: void = reversal; live computation makes "reversal" simply a status filter).
- **Bank txns do NOT auto-post journal entries** (deliberate CI3 deviation): they are the operational feed for reconciliation; ledger posting stays manual so automatic postings can never double-count with manual journals.
- Dates are UTC day bounds (`YYYY-MM-DD` → T00:00:00.000Z … +24h−1ms).
- Trial balance puts each account's NET balance in its natural column (negative balances flip sides) — grand totals prove ΣDr === ΣCr.

## Deliberate CI3 scope cuts (out of scope for this task)
Budgets/budget-vs-actual, fiscal years (so balance-sheet net income is cumulative-to-date, not current-year), a dedicated audit-trail page (journals keep createdByName/postedByName), and a cash-flow statement.

## Key facts for later agents
- Smoke users: bursar@nyansapo.gh (ACCOUNTANT — has `accounts.view`+`accounts.manage`), teacher@/cashier@ (no accounts perms → 403 both GET and POST). School code "GEA".
- The smoke never touches the seeded IN_PROGRESS reconciliation on the main bank — it builds its own bank account (`SMOKE Bank`, opening GH₵5,000) so the seed demo state survives every run.
- Completed reconciliations and posted/voided journals are **API-undeletable by design** — cleanup must go through Prisma (`reconciliation.deleteMany` cascades items; `journalEntry.deleteMany` cascades lines).
- `save-account`/`save-bank-account` are full-object saves: the UI always sends `isBank`/`isActive`, so omitting them on a raw API edit resets them to defaults — intentional, not a bug.
- GL `orderBy: [entry.entryDate asc, entry.createdAt asc]` — intra-entry line order isn't deterministic, but the running/closing balance is (sum-invariant).
- `add-statement-item`'s `matched` flag only compares |amount| vs the linked txn's amount (direction/date are auto-match concerns, not link-time blockers) — sufficient for the CI3 flow, noted in case someone wants stricter link validation later.
